## مشکل: ویروس مزاحم `Gallery.exe`

آیا از حذف بدافزار `Gallery.exe` خسته شده‌اید، فقط برای اینکه بعد از راه‌اندازی مجدد دوباره ظاهر شود؟ این ویروس رایج با قرار دادن فایل اجرایی خود در پوشه‌های کاربری و سیستمی خاص کار می‌کند. حتی پس از پاکسازی سیستم، اغلب به دلیل اینکه منبع اصلی آلودگی (مانند یک تسک زمان‌بندی شده یا فرآیند پنهان دیگر) سعی در ایجاد مجدد آن دارد، باز می‌گردد.

## راه‌حل: یک قلعه دیجیتال

**گالری-لاک** فقط ویروس را حذف نمی‌کند؛ بلکه یک قلعه دائمی به جای آن می‌سازد. این اسکریپت فایل‌های طعمه صفر بایتی (خالی) به نام `Gallery.exe` را در مکان‌های دقیقی که بدافزار هدف قرار می‌دهد ایجاد می‌کند. سپس مجوزهای امنیتی بسیار سختگیرانه (ACL) را اعمال می‌کند که بازنویسی یا حذف این طعمه‌ها را برای بدافزار **غیرممکن** می‌سازد.

نتیجه؟ تلاش بدافزار برای آلوده کردن مجدد سیستم شما در سطح سیستم‌عامل، هر بار مسدود می‌شود.

### روش توصیه شده: اجرا به عنوان SYSTEM با PsExec

این **امن‌ترین روش** است و تضمین می‌کند که اسکریپت می‌تواند قوی‌ترین محافظت‌های خود را اعمال کند.

1.  **دانلود PsExec:**
    *   مجموعه رسمی **Sysinternals Suite** را از مایکروسافت دانلود کنید: [**اینجا دانلود کنید**](https://learn.microsoft.com/en-us/sysinternals/downloads/psexec).
    *   فایل ZIP را در یک مکان ساده مانند `C:\Sysinternals` استخراج کنید.

2.  **باز کردن ترمینال با دسترسی Administrator:**
    *   کلیدهای `Win + X` را فشار دهید و **Terminal (Admin)** یا **Windows PowerShell (Admin)** را انتخاب کنید.

3.  **رفتن به پوشه PsExec:**
    *   در ترمینال، به دایرکتوری که PsExec را در آن استخراج کرده‌اید بروید.
      ```powershell
      cd C:\Sysinternals
      ```

### ⚡ استفاده سریع: دستور یک-خطی (از اینترنت)

برای نهایت راحتی، می‌توانید گالری-لاک را مستقیماً از وب اجرا کنید. یک **پاورشل در سطح SYSTEM** (با استفاده از روش PsExec بالا) باز کنید و یکی از دستورات زیر را استفاده کنید.

> [!NOTE]
> این دستور یک اسکریپت را از اینترنت دانلود و اجرا می‌کند. توصیه می‌کنیم قبل از اجرا، کد را بررسی کنید.

*   **برای نصب یا تعمیر قفل:**
    ```powershell
    iex ((iwr -Uri "https://raw.githubusercontent.com/Opselon/Gallery.Exe.Virus.Remover/main/scripts/gallery_lock.ps1" -UseBasicParsing).Content)
    ```

*   **برای بررسی وضعیت قفل:**
    ```powershell
    iex ((iwr -Uri "https://raw.githubusercontent.com/Opselon/Gallery.Exe.Virus.Remover/main/scripts/check_status.ps1" -UseBasicParsing).Content)
    ```

*   **برای حذف قفل (نیاز به دسترسی Administrator دارد):**
    ```powershell
    iex ((iwr -Uri "https://raw.githubusercontent.com/Opselon/Gallery.Exe.Virus.Remover/main/scripts/remove_gallery_lock.ps1" -UseBasicParsing).Content)
    ```
    
### 🚨 عیب‌یابی: خطاهای رایج

#### مشکل: لاگ من پر از خطاهای `FAIL: Target path is not on an NTFS drive` است.

اگر خروجی اسکریپت شما دقیقاً شبیه این است، با شکست‌های مکرر:

```
[INFO] --- Processing Target: User Profile (AppData\Roaming) ---
[ERROR] FAIL: Target path is not on an NTFS drive. ACLs cannot be applied.

[INFO] --- Processing Target: System Profile (32-bit) ---
[ERROR] FAIL: Target path is not on an NTFS drive. ACLs cannot be applied.

... (و به همین ترتیب برای همه اهداف)
```

#### **تشخیص: این لاگ اثبات قطعی است که شما اسکریپت را در یک پاورشل استاندارد Administrator اجرا می‌کنید، نه یک پاورشل در سطح SYSTEM.**

این رایج‌ترین اشتباه است. حتی وقتی با "Run as Administrator" اجرا می‌کنید، جلسه پاورشل شما امتیازات لازم برای تغییر پوشه‌های تحت مالکیت سیستم را ندارد. اسکریپت تلاش می‌کند نوع درایو را بررسی کند، به دلیل نداشتن مجوز شکست می‌خورد و به اشتباه خطای "not on an NTFS drive" را گزارش می‌دهد.

#### **راه‌حل: شما باید از PsExec استفاده کنید.**

1.  پنجره پاورشل فعلی خود را **ببندید** تا از سردرگمی جلوگیری کنید.
2.  به عقب برگردید و دستورالعمل‌های بخش **"نحوه استفاده: راهنمای ۲ دقیقه‌ای"** را با دقت دنبال کنید.
3.  یک پنجره پاورشل جدید با استفاده از دستور `psexec.exe -s -i powershell.exe` راه‌اندازی کنید.
4.  **هویت خود را تأیید کنید.** قبل از اجرای اسکریپت طعمه، `whoami` را تایپ کرده و Enter را فشار دهید. خروجی **باید** `nt authority\system` باشد. اگر چیز دیگری نشان داد، در پنجره اشتباهی هستید.
5.  پس از تأیید اینکه `SYSTEM` هستید، اسکریپت طعمه را دوباره اجرا کنید. همه خطاها برطرف خواهند شد.

## 🛠️ نحوه استفاده: راهنمای ۲ دقیقه‌ای

برای حداکثر کارایی، اسکریپت باید به عنوان `SYSTEM` اجرا شود. این بالاترین سطح اختیار در ویندوز است، حتی بالاتر از Administrator.

4.  **راه‌اندازی یک پاورشل در سطح SYSTEM:**
    *   دستور زیر را اجرا کنید. یک پنجره پاورشل جدید با امتیازات `SYSTEM` باز خواهد شد.
      ```powershell
      .\PsExec64.exe -i -s powershell.exe
      ```

5.  **اجرای اسکریپت گالری-لاک:**
    *   در **پنجره جدید SYSTEM**، به محلی که `Gallery-Lock.ps1` را ذخیره کرده‌اید بروید.
    *   ابتدا، سیاست اجرایی را برای این جلسه تنظیم کنید، سپس اسکریپت را اجرا کنید.
      ```powershell
      # اجازه دادن به اسکریپت برای اجرا فقط در این پنجره
      Set-ExecutionPolicy Bypass -Scope Process -Force
      
      # اجرای اسکریپت (از مسیر صحیح استفاده کنید)
      .\Gallery-Lock.ps1
      ```

**تمام شد!** فایل‌های طعمه اکنون در جای خود قرار گرفته و مستحکم شده‌اند. می‌توانید همه پنجره‌ها را ببندید.

### نحوه استفاده با پایتون

این پروژه شامل یک پوشش (wrapper) پایتون برای استفاده آسان‌تر است.

#### نصب

1.  **اطمینان حاصل کنید که پایتون 3 را نصب کرده‌اید.**
2.  **وابستگی‌های مورد نیاز را نصب کنید:**
    ```bash
    pip install -r requirements.txt
    ```

#### استفاده

می‌توانید از پوشش پایتون برای نصب، حذف یا بررسی وضعیت طعمه‌های گالری-لاک استفاده کنید.

*   **استفاده مستقیم از پایتون:**
    ```bash
    python3 -m gallery_lock install
    python3 -m gallery_lock remove
    python3 -m gallery_lock status
    ```
    دستور `status` یک بررسی امنیتی کامل روی فایل‌های طعمه انجام می‌دهد، نه تنها وجود آنها، بلکه اندازه فایل، مالکیت و مجوزها را نیز برای اطمینان از عدم دستکاری بررسی می‌کند. در نهایت یک وضعیت واضح `SECURE` (امن) یا `INSECURE` (ناامن) گزارش می‌دهد.

*   **استفاده از Batch یا CMD:**
    ```bash
    run.bat install
    run.cmd remove
    run.bat status
    ```

## 🧱 چگونه کار می‌کند: یک تجزیه و تحلیل فنی

اثربخشی اسکریپت از یک استراتژی امنیتی چند لایه ناشی می‌شود:

1.  **🔍 اسکن و پاکسازی:** ابتدا فایل‌های `Gallery.exe` موجود را در مکان‌های هدف بررسی و حذف می‌کند و از یک شروع پاک اطمینان حاصل می‌کند.
2.  **📝 ایجاد طعمه:** یک فایل خالی و 0 بایتی به نام `Gallery.exe` ایجاد می‌شود. بی‌ضرر است و فضایی را اشغال نمی‌کند.
3.  **🛡️ ساخت قلعه (سخت‌سازی ACL):** این مهم‌ترین مرحله است. اسکریپت لیست کنترل دسترسی (ACL) فایل را تغییر می‌دهد:
    *   **مسدود کردن وراثت:** از به ارث بردن مجوزها از پوشه والد خود جلوگیری می‌کند. این آن را از هرگونه تغییر امنیتی در آینده جدا می‌کند.
    *   **رد کردن همه:** یک قانون صریح `Deny FullControl` را برای گروه `Everyone` اضافه می‌کند. در ویندوز، یک `Deny` صریح همیشه بر هر قانون `Allow` ارجحیت دارد. این بدان معناست که هیچ کاربری، **حتی یک مدیر**، نمی‌تواند در فایل بنویسد، آن را تغییر دهد یا حذف کند.
    *   **اعطای کنترل به SYSTEM:** تضمین می‌کند که فقط حساب `NT AUTHORITY\SYSTEM` یا `TrustedInstaller` دارای `FullControl` است. این برای یکپارچگی سیستم ضروری است اما حسابی است که بدافزار (و کاربران) به راحتی نمی‌توانند از آن استفاده کنند.
4.  **👻 نامرئی شدن:** در نهایت، ویژگی‌های فایل را به `Hidden` و `System` تنظیم می‌کند و آن را از نمای استاندارد در فایل اکسپلورر پنهان می‌کند تا از کشف یا دستکاری تصادفی جلوگیری شود.

## ⚠️ هشدارهای مهم و نحوه لغو

> [!WARNING]
> **این اسکریپت فایلی را ایجاد می‌کند که حذف آن *عمداً* دشوار است، حتی برای شما.** این را روی هیچ فایلی که ممکن است بعداً به آن نیاز داشته باشید اجرا نکنید. این به طور خاص برای مسدود کردن مسیرهای بدافزار شناخته شده طراحی شده است.

### نحوه حذف دستی یک فایل طعمه قفل شده

اگر زمانی نیاز به حذف طعمه‌ها داشتید، باید به صورت دستی حفاظت را به عنوان **Administrator** معکوس کنید.

1.  **باز کردن ترمینال با دسترسی Administrator** (`Win + X` > Terminal (Admin)).
2.  **گرفتن مالکیت** فایل. مسیر را با مسیر صحیح جایگزین کنید.
    *برای فایل کاربری:*
    ```cmd
    takeown /f "%APPDATA%\Gallery.exe"
    ```
    *برای فایل سیستمی:*
    ```cmd
    takeown /f "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe"
    ```
3.  **بازنشانی مجوزها** برای به ارث بردن از پوشه والد.
    *برای فایل کاربری:*
    ```cmd
    icacls "%APPDATA%\Gallery.exe" /reset
    ```
    *برای فایل سیستمی:*
    ```cmd
    icacls "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe" /reset
    ```
4.  اکنون می‌توانید **فایل را به طور معمول حذف کنید**.
    ```powershell
    Remove-Item -Path "$env:APPDATA\Gallery.exe" -Force
    Remove-Item -Path "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe" -Force
    ```

## 🐍 SafeRemover - اسکنر بدافزار پایتون

**SafeRemover.py** یک اسکریپت پایتون محتاط و تعاملی است که برای اسکن و خنثی‌سازی طیف وسیع‌تری از تهدیدها فراتر از `Gallery.exe` طراحی شده است. این اسکریپت از یک پایگاه داده JSON قابل تنظیم برای امضای تهدیدها استفاده می‌کند و با یک رویکرد چند لایه، ایمنی کاربر را در اولویت قرار می‌دهد.

### ✨ ویژگی‌های کلیدی

| ویژگی | توضیحات |
| :--- | :--- |
| 🛡️ **اسکن مبتنی بر امضا** | از یک فایل `threat_database.json` خوانا برای شناسایی تهدیدها بر اساس نام فایل، اندازه فایل یا هش SHA256 استفاده می‌کند. |
| 🕵️ **اسکن جامع** | مکان‌های رایج بدافزار را اسکن می‌کند، از جمله پوشه‌های AppData، Temp، پوشه‌های Startup کاربر، و بردارهای پایداری مانند کلیدهای Run در رجیستری و تسک‌های زمان‌بندی شده. |
| 🚫 **حالت پیش‌فرض فقط-خواندنی** | حالت پیش‌فرض `--scan` کاملاً فقط-خواندنی است و **هیچ تغییری** در سیستم شما ایجاد نمی‌کند. فقط آنچه را که پیدا می‌کند گزارش می‌دهد. |
| ✅ **پاکسازی تعاملی** | حالت `--clean` برای **هر اقدام** به تأیید کاربر نیاز دارد. هیچ چیزی به طور خودکار حذف یا تغییر نمی‌کند. |
| 📦 **قرنطینه امن** | فایل‌ها به یک پوشه قرنطینه امن (`C:\SafeRemover\Quarantine`) منتقل می‌شوند، نه اینکه به طور دائم حذف شوند. |
| 📜 **پشتیبان‌گیری از رجیستری** | قبل از حذف یک کلید مشکوک در رجیستری، اسکریپت به طور خودکار از کلید والد در یک فایل `.reg` برای بازیابی آسان پشتیبان تهیه می‌کند. |
| ✍️ **گزارش‌گیری دقیق** | تمام اقدامات (اسکن‌ها، یافته‌ها، تأییدیه‌های کاربر، خطاها) در فایل `SafeRemover_Activity.log` برای یک ردپای حسابرسی کامل ثبت می‌شوند. |

### 🛠️ نحوه استفاده

اسکریپت از خط فرمان (ترمینال یا پاورشل) اجرا می‌شود.

1.  **یک ترمینال باز کنید:**
    *   ترمینال مورد نظر خود را باز کنید (مثلاً `cmd.exe`, `powershell.exe` یا Windows Terminal).
    *   به دایرکتوری که `SafeRemover.py` در آن قرار دارد بروید.

2.  **برای انجام اسکن فقط-خواندنی:**
    *   این دستور سیستم را اسکن کرده و یافته‌ها را بدون ایجاد هیچ تغییری گزارش می‌دهد.
    ```bash
    python SafeRemover.py --scan
    ```
    *(توجه: `--scan` عمل پیش‌فرض است، بنابراین می‌توانید فقط `python SafeRemover.py` را اجرا کنید)*

3.  **برای انجام پاکسازی تعاملی:**
    *   این دستور به **دسترسی Administrator** نیاز دارد. روی برنامه ترمینال خود راست کلیک کرده و "Run as administrator" را انتخاب کنید.
    *   اسکریپت تهدیدها را اسکن کرده و سپس برای تأیید یا رد هر اقدام از شما یک به یک سؤال می‌کند.
    ```bash
    python SafeRemover.py --clean
    ```

### ⚙️ پایگاه داده تهدیدها

قدرت این ابزار از فایل `threat_database.json` ناشی می‌شود. شما می‌توانید به راحتی تعاریف تهدید خود را اضافه کنید.

*   **تهدیدهای مبتنی بر فایل:**
    ```json
    {
      "name": "ExampleThreat.exe",
      "type": "file",
      "signatures": {
        "filenames": ["ExampleThreat.exe", "evil.exe"],
        "hashes": ["sha256_hash_goes_here"],
        "file_sizes": [12345]
      }
    }
    ```
*   **تهدیدهای مبتنی بر رجیستری:**
    ```json
    {
      "name": "Suspicious Run Key",
      "type": "registry",
      "signatures": {
        "value_patterns": ["C:\\Users\\.*\\AppData\\Roaming\\evil.exe"]
      }
    }
    ```
    فیلد `value_patterns` از عبارات منظم (regular expressions) برای تطبیق مسیرهای مشکوک در مقادیر رجیستری استفاده می‌کند.
