## مسئلہ: پریشان کن `Gallery.exe` وائرس

کیا آپ `Gallery.exe` میلویئر کو ہٹانے سے تھک گئے ہیں، صرف اسے دوبارہ شروع کرنے کے بعد دوبارہ ظاہر ہونے کے لیے؟ یہ عام وائرس مخصوص صارف اور سسٹم فولڈرز میں اپنی قابل عمل فائل رکھ کر کام کرتا ہے۔ اپنے سسٹم کو صاف کرنے کے بعد بھی، یہ اکثر واپس آجاتا ہے کیونکہ اصل انفیکشن کا ذریعہ (جیسے ایک طے شدہ ٹاسک یا کوئی اور پوشیدہ عمل) اسے دوبارہ بنانے کی کوشش کرتا ہے۔

## حل: ایک ڈیجیٹل قلعہ

**گیلری لاک** صرف وائرس کو نہیں ہٹاتا؛ یہ اس کی جگہ ایک مستقل قلعہ بناتا ہے۔ اسکرپٹ میلویئر کے ذریعے نشانہ بنائے گئے عین مقامات پر `Gallery.exe` نامی صفر بائٹ (خالی) ڈیکوئے فائلیں بناتا ہے۔ پھر یہ انتہائی سخت حفاظتی اجازتیں (ACLs) لاگو کرتا ہے جو ان ڈیکوئے کو میلویئر کے ذریعے **اوور رائٹ یا حذف کرنا ناممکن** بنا دیتی ہیں۔

نتیجہ؟ آپ کے سسٹم کو دوبارہ متاثر کرنے کی میلویئر کی کوشش آپریٹنگ سسٹم کی سطح پر ہر بار روک دی جاتی ہے۔

## 🛠️ استعمال کیسے کریں: 2 منٹ کی گائیڈ

زیادہ سے زیادہ تاثیر کے لیے، اسکرپٹ کو `SYSTEM` کے طور پر چلایا جانا چاہیے۔ یہ ونڈوز پر سب سے اعلیٰ اتھارٹی کی سطح ہے، یہاں تک کہ منتظم سے بھی اوپر۔

### تجویز کردہ طریقہ: PsExec کے ساتھ SYSTEM کے طور پر چلائیں

یہ **سب سے محفوظ طریقہ** ہے اور اس بات کی ضمانت دیتا ہے کہ اسکرپٹ اپنی مضبوط ترین حفاظتوں کا اطلاق کر سکتا ہے۔

1.  **PsExec ڈاؤن لوڈ کریں:**
    *   مائیکروسافٹ سے آفیشل **Sysinternals Suite** ڈاؤن لوڈ کریں: [**یہاں سے ڈاؤن لوڈ کریں**](https://learn.microsoft.com/en-us/sysinternals/downloads/psexec)۔
    *   زپ فائل کو `C:\Sysinternals` جیسی سادہ جگہ پر نکالیں۔

2.  **ایک ایڈمنسٹریٹر ٹرمینل کھولیں:**
    *   `Win + X` دبائیں اور **ٹرمینل (ایڈمن)** یا **ونڈوز پاور شیل (ایڈمن)** منتخب کریں۔

3.  **PsExec فولڈر میں جائیں:**
    *   ٹرمینل میں، اس ڈائرکٹری میں جائیں جہاں آپ نے PsExec نکالا تھا۔
      ```powershell
      cd C:\Sysinternals
      ```

4.  **ایک سسٹم سطح کا پاور شیل لانچ کریں:**
    *   درج ذیل کمانڈ چلائیں۔ `SYSTEM` مراعات کے ساتھ ایک نئی پاور شیل ونڈو کھلے گی۔
      ```powershell
      .\PsExec64.exe -i -s powershell.exe
      ```

5.  **گیلری لاک اسکرپٹ چلائیں:**
    *   **نئی سسٹم ونڈو** میں، اس جگہ پر جائیں جہاں آپ نے `Gallery-Lock.ps1` محفوظ کیا تھا۔
    *   سب سے پہلے، اس واحد سیشن کے لیے عملدرآمد کی پالیسی سیٹ کریں, پھر اسکرپٹ چلائیں۔
      ```powershell
      # اس ونڈو میں صرف اسکرپٹ چلانے کی اجازت دیں
      Set-ExecutionPolicy Bypass -Scope Process -Force

      # اسکرپٹ چلائیں (صحیح راستہ استعمال کریں)
      .\Gallery-Lock.ps1
      ```

**بس!** ڈیکوئے فائلیں اب جگہ پر ہیں اور سخت ہو گئی ہیں۔ آپ تمام ونڈوز بند کر سکتے ہیں۔

<details>
  <summary><strong>متبادل طریقہ: ایڈمنسٹریٹر کے طور پر چلائیں (کم محفوظ)</strong></summary>

  > [!NOTE]
  > یہ طریقہ کام کرتا ہے، لیکن فائل کا تحفظ اتنا مضبوط نہیں ہے کیونکہ ایک منتظم اب بھی زیادہ آسانی سے ملکیت لے سکتا ہے۔ اس کی سفارش صرف اس صورت میں کی جاتی ہے جب آپ PsExec استعمال نہیں کر سکتے۔

  1. `Gallery-Lock.ps1` اسکرپٹ فائل پر **دائیں کلک کریں**۔
  2. **"پاور شیل کے ساتھ چلائیں"** منتخب کریں۔
  3. اگر کہا جائے تو، اسے منتظم کے حقوق دینے کے لیے UAC (یوزر اکاؤنٹ کنٹرول) پرامپٹ کو منظور کریں۔

  اسکرپٹ آپ کو مطلع کرے گا کہ یہ ایڈمنسٹریٹر کے طور پر چل رہا ہے نہ کہ SYSTEM کے طور پر۔
</details>

## 🗺️ محفوظ فائل کے مقامات

اسکرپٹ درج ذیل معیاری میلویئر راستوں میں ڈیکوئے بناتا اور ان کی حفاظت کرتا ہے:

| پروفائل کی قسم | راستہ |
| :--- | :--- |
| **صارف پروفائل** | `%APPDATA%\Gallery.exe` |
| **سسٹم پروفائل** | `C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe` |

---

## 🧱 یہ کیسے کام کرتا ہے: ایک تکنیکی جائزہ

اسکرپٹ کی تاثیر ایک کثیر سطحی حفاظتی حکمت عملی سے آتی ہے:

1.  **🔍 اسکین اور صاف کریں:** یہ پہلے ہدف کے مقامات پر کسی بھی موجودہ `Gallery.exe` فائلوں کی جانچ کرتا اور انہیں حذف کرتا ہے، ایک صاف سلیٹ کو یقینی بناتا ہے۔
2.  **📝 ڈیکوئے بنائیں:** `Gallery.exe` نامی ایک خالی 0 بائٹ فائل بنائی جاتی ہے۔ یہ بے ضرر ہے اور کوئی جگہ نہیں لیتی ہے۔
3.  **🛡️ قلعہ بنائیں (ACL ہارڈننگ):** یہ سب سے اہم قدم ہے۔ اسکرپٹ فائل کی ایکسیس کنٹرول لسٹ (ACL) میں ترمیم کرتا ہے:
    *   **وراثت کو روکتا ہے:** یہ فائل کو اپنے پیرنٹ فولڈر سے اجازتیں وراثت میں لینے سے روکتا ہے۔ یہ اسے مستقبل میں کسی بھی حفاظتی تبدیلی سے الگ کرتا ہے۔
    *   **سب کو انکار کرتا ہے:** یہ `Everyone` گروپ کے لیے ایک واضح `Deny FullControl` اصول شامل کرتا ہے۔ ونڈوز میں، ایک واضح `Deny` اصول ہمیشہ کسی بھی `Allow` اصول کو اوور رائیڈ کرتا ہے۔ اس کا مطلب ہے کہ کوئی بھی صارف، **یہاں تک کہ ایک منتظم بھی**، فائل کو لکھ، ترمیم یا حذف نہیں کر سکتا۔
    *   **سسٹم کو کنٹرول دیتا ہے:** یہ یقینی بناتا ہے کہ صرف `NT AUTHORITY\SYSTEM` یا `TrustedInstaller` اکاؤنٹ کے پاس `FullControl` ہے۔ یہ سسٹم کی سالمیت کے لیے ضروری ہے لیکن یہ ایک ایسا اکاؤنٹ ہے جسے میلویئر (اور صارفین) آسانی سے استعمال نہیں کر سکتے۔
4.  **👻 غیر مرئی ہو جائیں:** آخر میں، یہ فائل کی خصوصیات کو `پوشیدہ` اور `سسٹم` پر سیٹ کرتا ہے، اسے فائل ایکسپلورر میں معیاری منظر سے چھپاتا ہے تاکہ حادثاتی دریافت یا چھیڑ چھاڑ کو روکا جا سکے۔

## ⚠️ اہم انتباہات اور انڈو کیسے کریں

> [!WARNING]
> **یہ اسکرپٹ ایک ایسی فائل بناتا ہے جسے ہٹانا *جان بوجھ کر* مشکل ہے، یہاں تک کہ آپ کے لیے بھی۔** اسے کسی ایسی فائل پر نہ چلائیں جس تک آپ کو بعد میں رسائی کی ضرورت پڑ سکتی ہے۔ یہ خاص طور پر معلوم میلویئر راستوں کو روکنے کے لیے ڈیزائن کیا گیا ہے۔

### ایک مقفل ڈیکوئے فائل کو دستی طور پر کیسے ہٹائیں

اگر آپ کو کبھی بھی ڈیکوئے کو ہٹانے کی ضرورت ہو، تو آپ کو **ایڈمنسٹریٹر** کے طور پر دستی طور پر تحفظ کو الٹنا ہوگا۔

1.  **ایک ایڈمنسٹریٹر ٹرمینل کھولیں** (`Win + X` > ٹرمینل (ایڈمن))۔
2.  فائل کی **ملکیت لیں**۔ راستے کو صحیح سے تبدیل کریں۔
    *صارف فائل کے لیے:*
    ```cmd
    takeown /f "%APPDATA%\Gallery.exe"
    ```
    *سسٹم فائل کے لیے:*
    ```cmd
    takeown /f "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe"
    ```
3.  پیرنٹ فولڈر سے وراثت میں لینے کے لیے **اجازتیں ری سیٹ کریں**۔
    *صارف فائل کے لیے:*
    ```cmd
    icacls "%APPDATA%\Gallery.exe" /reset
    ```
    *سسٹم فائل کے لیے:*
    ```cmd
    icacls "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe" /reset
    ```
4.  اب آپ عام طور پر **فائل حذف** کر سکتے ہیں۔
    ```powershell
    Remove-Item -Path "$env:APPDATA\Gallery.exe" -Force
    ```
