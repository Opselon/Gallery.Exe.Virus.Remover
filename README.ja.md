## 問題点：迷惑な`Gallery.exe`ウイルス

`Gallery.exe`マルウェアを削除しても、再起動後に再び現れるのにうんざりしていませんか？この一般的なウイルスは、特定のユーザーおよびシステムフォルダーに実行可能ファイルを配置することで機能します。システムをクリーンアップした後でも、元の感染源（スケジュールされたタスクや別の隠しプロセスなど）が再作成しようとするため、しばしば復活します。

## 解決策：デジタル要塞

**Gallery-Lock**はウイルスを削除するだけではありません。その場所に永続的な要塞を構築します。このスクリプトは、マルウェアが標的とする正確な場所に`Gallery.exe`という名前のゼロバイト（空）のデコイファイルを作成します。次に、非常に厳格なセキュリティ許可（ACL）を適用して、これらのデコイをマルウェアが**上書きまたは削除できないようにします**。

その結果は？マルウェアがシステムに再感染しようとする試みは、オペレーティングシステムレベルで毎回ブロックされます。

## 🛠️ 使用方法：2分ガイド

最大限の効果を得るには、スクリプトを`SYSTEM`として実行する必要があります。これは、管理者よりも高いWindowsの最高の権限レベルです。

### 推奨方法：PsExecを使用してSYSTEMとして実行

これは**最も安全な方法**であり、スクリプトが最も強力な保護を適用できることを保証します。

1.  **PsExecをダウンロード：**
    *   Microsoftから公式の**Sysinternals Suite**をダウンロードします：[**こちらからダウンロード**](https://learn.microsoft.com/en-us/sysinternals/downloads/psexec)。
    *   ZIPファイルを`C:\Sysinternals`などの簡単な場所に抽出します。

2.  **管理者ターミナルを開く：**
    *   `Win + X`を押し、**ターミナル（管理者）**または**Windows PowerShell（管理者）**を選択します。

3.  **PsExecフォルダーに移動：**
    *   ターミナルで、PsExecを抽出したディレクトリに移動します。
      ```powershell
      cd C:\Sysinternals
      ```

4.  **SYSTEMレベルのPowerShellを起動：**
    *   次のコマンドを実行します。`SYSTEM`権限を持つ新しいPowerShellウィンドウが開きます。
      ```powershell
      .\PsExec64.exe -i -s powershell.exe
      ```

5.  **Gallery-Lockスクリプトを実行：**
    *   **新しいSYSTEMウィンドウ**で、`Gallery-Lock.ps1`を保存した場所に移動します。
    *   まず、この単一セッションの実行ポリシーを設定し、次にスクリプトを実行します。
      ```powershell
      # このウィンドウでのみスクリプトの実行を許可
      Set-ExecutionPolicy Bypass -Scope Process -Force

      # スクリプトを実行（正しいパスを使用）
      .\Gallery-Lock.ps1
      ```

**以上です！** これでデコイファイルが配置され、強化されました。すべてのウィンドウを閉じることができます。

<details>
  <summary><strong>代替方法：管理者として実行（安全性が低い）</strong></summary>

  > [!NOTE]
  > この方法は機能しますが、管理者がより簡単に所有権を取得できるため、ファイルの保護はそれほど強力ではありません。PsExecを使用できない場合にのみ推奨されます。

  1. `Gallery-Lock.ps1`スクリプトファイルを**右クリック**します。
  2. **「PowerShellで実行」**を選択します。
  3. プロンプトが表示されたら、UAC（ユーザーアカウント制御）プロンプトを承認して管理者権限を付与します。

  スクリプトは、SYSTEMではなく管理者として実行されていることを通知します。
</details>

## 🗺️ 保護されたファイルの場所

スクリプトは、次の標準的なマルウェアパスにデコイを作成して保護します。

| プロファイルタイプ | パス |
| :--- | :--- |
| **ユーザープロファイル** | `%APPDATA%\Gallery.exe` |
| **システムプロファイル** | `C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe` |

## 🧱 仕組み：技術的な内訳

スクリプトの有効性は、多層的なセキュリティ戦略から生まれます。

1.  **🔍 スキャンとクリーン：** まず、ターゲットの場所にある既存の`Gallery.exe`ファイルをチェックして削除し、クリーンな状態を確保します。
2.  **📝 デコイの作成：** `Gallery.exe`という名前の空の0バイトファイルが作成されます。これは無害で、スペースを占有しません。
3.  **🛡️ 要塞の構築（ACL強化）：** これが最も重要なステップです。スクリプトはファイルのアクセス制御リスト（ACL）を変更します。
    *   **継承のブロック：** ファイルが親フォルダーからアクセス許可を継承するのを防ぎます。これにより、将来のセキュリティ変更から隔離されます。
    *   **すべての人を拒否：** `Everyone`グループに対して明示的な`Deny FullControl`ルールを追加します。Windowsでは、明示的な`Deny`ルールは常に`Allow`ルールを上書きします。これは、管理者であっても**誰も**ファイルを書き込み、変更、または削除できないことを意味します。
    *   **SYSTEMに制御を許可：** `NT AUTHORITY\SYSTEM`または`TrustedInstaller`アカウントのみが`FullControl`を持つことを保証します。これはシステムの整合性のために必要ですが、マルウェア（およびユーザー）が簡単に使用できないアカウントです。
4.  **👻 不可視化：** 最後に、ファイル属性を`隠し`および`システム`に設定し、ファイルエクスプローラーの標準ビューから非表示にして、偶発的な発見や改ざんを防ぎます。

## ⚠️ 重要な警告と元に戻す方法

> [!WARNING]
> **このスクリプトは、あなたにとっても削除が*意図的に*困難なファイルを作成します。** 後でアクセスする必要がある可能性のあるファイルでこれを実行しないでください。これは、既知のマルウェアパスをブロックするために特別に設計されています。

### ロックされたデコイファイルを手動で削除する方法

デコイを削除する必要がある場合は、**管理者**として手動で保護を元に戻す必要があります。

1.  **管理者ターミナルを開く**（`Win + X` > ターミナル（管理者））。
2.  ファイルの**所有権を取得**します。パスを正しいものに置き換えてください。
    *ユーザーファイルの場合：*
    ```cmd
    takeown /f "%APPDATA%\Gallery.exe"
    ```
    *システムファイルの場合：*
    ```cmd
    takeown /f "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe"
    ```
3.  親フォルダーから継承するように**アクセス許可をリセット**します。
    *ユーザーファイルの場合：*
    ```cmd
    icacls "%APPDATA%\Gallery.exe" /reset
    ```
    *システムファイルの場合：*
    ```cmd
    icacls "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe" /reset
    ```
4.  これで、通常どおり**ファイルを削除**できます。
    ```powershell
    Remove-Item -Path "$env:APPDATA\Gallery.exe" -Force
    ```

## 🔎 トラブルシューティングとFAQ

| 症状/質問 | 解決策/説明 |
| :--- | :--- |
| ❌ **スクリプト実行中の「アクセスが拒否されました」エラー。** | SYSTEMではなく管理者として実行している場合に予想されます。スクリプトは`SYSTEM`を所有者として設定できません。**完全な保護のためにPsExecメソッドを使用してください。** |
| 📜 **「このシステムではスクリプトの実行が無効になっています。」エラー。** | これはPowerShellの実行ポリシーエラーです。メインスクリプトを実行する前に`Set-ExecutionPolicy Bypass -Scope Process -Force`を実行することで、現在のプロセスに対してこれをバイパスできます。 |
| 🪟 **ファイルエクスプローラーで`Gallery.exe`ファイルが表示されません。** | これは意図的なものです。ファイルは非表示になっています。表示するには、ファイルエクスプローラー > `表示` > `オプション` > `表示`タブに移動し、**「隠しファイルを表示する...」**をオンにし、**「保護されたオペレーティングシステムファイルを隠す」**をオフにします。 |
| 🗑️ **管理者であってもファイルを削除できません！** | これはスクリプトが正しく機能していることを意味します！あなたを含むすべての人をブロックするように設計されています。削除するには、**[元に戻す方法](#️-重要な警告と元に戻す方法)**セクションの手順に従ってください。 |
| 🤔 **なぜ`SYSTEM`として実行することがそれほど重要なのですか？** | `SYSTEM`アカウントはWindowsの究極の権限です。`SYSTEM`をデコイの所有者にすることで、管理者が明示的に所有権を取得しない限り、簡単に変更することを防ぎます。管理者権限で実行されているマルウェアはブロックされ、これは大きなセキュリティ上の勝利です。 |
