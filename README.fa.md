## مشکل: ویروس مزاحم `Gallery.exe`

آیا از حذف بدافزار `Gallery.exe` خسته شده اید، فقط برای اینکه بعد از راه اندازی مجدد دوباره ظاهر شود؟ این ویروس رایج با قرار دادن فایل اجرایی خود در پوشه های کاربری و سیستمی خاص کار می کند. حتی پس از پاکسازی سیستم، اغلب به دلیل اینکه منبع اصلی آلودگی (مانند یک کار برنامه ریزی شده یا فرآیند پنهان دیگر) سعی در ایجاد مجدد آن دارد، باز می گردد.

## راه حل: یک قلعه دیجیتال

**گالری-لاک** فقط ویروس را حذف نمی کند؛ بلکه یک قلعه دائمی به جای آن می سازد. این اسکریپت فایل های طعمه صفر بایتی (خالی) به نام `Gallery.exe` را در مکان های دقیقی که بدافزار هدف قرار می دهد ایجاد می کند. سپس مجوزهای امنیتی بسیار سختگیرانه (ACL) را اعمال می کند که بازنویسی یا حذف این طعمه ها را برای بدافزار **غیرممکن** می کند.

نتیجه؟ تلاش بدافزار برای آلوده کردن مجدد سیستم شما در سطح سیستم عامل، هر بار مسدود می شود.

## 🛠️ نحوه استفاده: راهنمای 2 دقیقه ای

برای حداکثر کارایی، اسکریپت باید به عنوان `SYSTEM` اجرا شود. این بالاترین سطح اختیار در ویندوز است، حتی بالاتر از مدیر.

### روش توصیه شده: اجرا به عنوان SYSTEM با PsExec

این **امن ترین روش** است و تضمین می کند که اسکریپت می تواند قوی ترین محافظت های خود را اعمال کند.

1.  **دانلود PsExec:**
    *   مجموعه رسمی **Sysinternals Suite** را از مایکروسافت دانلود کنید: [**اینجا دانلود کنید**](https://learn.microsoft.com/en-us/sysinternals/downloads/psexec).
    *   فایل ZIP را در یک مکان ساده مانند `C:\Sysinternals` استخراج کنید.

2.  **باز کردن ترمینال مدیر:**
    *   `Win + X` را فشار دهید و **ترمینال (مدیر)** یا **Windows PowerShell (مدیر)** را انتخاب کنید.

3.  **رفتن به پوشه PsExec:**
    *   در ترمینال، به دایرکتوری که PsExec را در آن استخراج کرده اید بروید.
      ```powershell
      cd C:\Sysinternals
      ```

4.  **راه اندازی یک پاورشل سطح SYSTEM:**
    *   دستور زیر را اجرا کنید. یک پنجره پاورشل جدید با امتیازات `SYSTEM` باز می شود.
      ```powershell
      .\PsExec64.exe -i -s powershell.exe
      ```

5.  **اجرای اسکریپت گالری-لاک:**
    *   در **پنجره جدید SYSTEM**، به جایی که `Gallery-Lock.ps1` را ذخیره کرده اید بروید.
    *   ابتدا، خط مشی اجرا را برای این جلسه واحد تنظیم کنید، سپس اسکریپت را اجرا کنید.
      ```powershell
      # اجازه دادن به اسکریپت برای اجرا فقط در این پنجره
      Set-ExecutionPolicy Bypass -Scope Process -Force

      # اجرای اسکریپت (از مسیر صحیح استفاده کنید)
      .\Gallery-Lock.ps1
      ```

**همین!** فایل های طعمه اکنون در جای خود قرار گرفته و سخت شده اند. می توانید همه پنجره ها را ببندید.

### نحوه استفاده با پایتون

این پروژه شامل یک لفاف پایتون برای استفاده آسان تر است.

#### نصب

1.  **اطمینان حاصل کنید که پایتون 3 را نصب کرده اید.**
2.  **وابستگی های مورد نیاز را نصب کنید:**
    ```bash
    pip install -r requirements.txt
    ```

#### استفاده

می توانید از لفاف پایتون برای نصب، حذف یا بررسی وضعیت طعمه های گالری-لاک استفاده کنید.

*   **استفاده مستقیم از پایتون:**
    ```bash
    python3 -m gallery_lock install
    python3 -m gallery_lock remove
    python3 -m gallery_lock status
    ```
*   **استفاده از Batch یا CMD:**
    ```bash
    run.bat install
    run.cmd remove
    run.bat status
    ```

  > [!NOTE]
  > این روش کار می کند، اما حفاظت از فایل به اندازه کافی قوی نیست زیرا یک مدیر هنوز هم می تواند مالکیت را راحت تر به دست آورد. فقط در صورتی توصیه می شود که نتوانید از PsExec استفاده کنید.

  2. **"Run with PowerShell"** را انتخاب کنید.

## 🧱 چگونه کار می کند: یک تجزیه و تحلیل فنی

اثربخشی اسکریپت از یک استراتژی امنیتی چند لایه ناشی می شود:

1.  **🔍 اسکن و پاکسازی:** ابتدا فایل های `Gallery.exe` موجود را در مکان های هدف بررسی و حذف می کند و از یک لوح پاک اطمینان حاصل می کند.
2.  **📝 ایجاد طعمه:** یک فایل خالی و 0 بایتی به نام `Gallery.exe` ایجاد می شود. بی ضرر است و فضایی را اشغال نمی کند.
3.  **🛡️ ساخت قلعه (سخت شدن ACL):** این مهمترین مرحله است. اسکریپت لیست کنترل دسترسی (ACL) فایل را تغییر می دهد:
    *   **مسدود کردن وراثت:** از به ارث بردن مجوزها از پوشه والد خود جلوگیری می کند. این آن را از هرگونه تغییر امنیتی در آینده جدا می کند.
    *   **رد کردن همه:** یک قانون صریح `Deny FullControl` را برای گروه `Everyone` اضافه می کند. در ویندوز، یک `Deny` صریح همیشه بر هر قانون `Allow` ارجحیت دارد. این بدان معناست که هیچ کاربری، **حتی یک مدیر**، نمی تواند در فایل بنویسد، آن را تغییر دهد یا حذف کند.
    *   **اعطای کنترل SYSTEM:** تضمین می کند که فقط حساب `NT AUTHORITY\SYSTEM` یا `TrustedInstaller` دارای `FullControl` است. این برای یکپارچگی سیستم ضروری است اما حسابی است که بدافزار (و کاربران) به راحتی نمی توانند از آن استفاده کنند.
4.  **👻 نامرئی شدن:** در نهایت، ویژگی های فایل را به `Hidden` و `System` تنظیم می کند و آن را از نمای استاندارد در فایل اکسپلورر پنهان می کند تا از کشف یا دستکاری تصادفی جلوگیری شود.

## ⚠️ هشدارهای مهم و نحوه لغو

> [!WARNING]
> **این اسکریپت فایلی را ایجاد می کند که حذف آن *عمداً* دشوار است، حتی برای شما.** این را روی هیچ فایلی که ممکن است بعداً به آن نیاز داشته باشید اجرا نکنید. این به طور خاص برای مسدود کردن مسیرهای بدافزار شناخته شده طراحی شده است.

### نحوه حذف دستی یک فایل طعمه قفل شده

اگر زمانی نیاز به حذف طعمه ها داشتید، باید به صورت دستی حفاظت را به عنوان **مدیر** معکوس کنید.

1.  **باز کردن ترمینال مدیر** (`Win + X` > ترمینال (مدیر)).
2.  **گرفتن مالکیت** فایل. مسیر را با مسیر صحیح جایگزین کنید.
    *برای فایل کاربری:*
    ```cmd
    takeown /f "%APPDATA%\Gallery.exe"
    ```
    *برای فایل سیستمی:*
    ```cmd
    takeown /f "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe"
    ```
3.  **بازنشانی مجوزها** برای به ارث بردن از پوشه والد.
    *برای فایل کاربری:*
    ```cmd
    icacls "%APPDATA%\Gallery.exe" /reset
    ```
    *برای فایل سیستمی:*
    ```cmd
    icacls "C:\Windows\SysWOW64\config\systemprofile\AppData\Roaming\Gallery.exe" /reset
    ```
4.  اکنون می توانید **فایل را به طور معمول حذف کنید**.
    ```powershell
    Remove-Item -Path "$env:APPDATA\Gallery.exe" -Force
    ```

| ❌ **خطای "Access is denied" در حین اجرای اسکریپت.** | این در صورتی انتظار می رود که به عنوان مدیر به جای SYSTEM در حال اجرا باشید. اسکریپت نمی تواند `SYSTEM` را به عنوان مالک تنظیم کند. **برای حفاظت کامل از روش PsExec استفاده کنید.** |
| 📜 **خطای "Running scripts is disabled on this system."** | این یک خطای خط مشی اجرای پاورشل است. می توانید با اجرای `Set-ExecutionPolicy Bypass -Scope Process -Force` قبل از اجرای اسکریپت اصلی، آن را برای فرآیند فعلی دور بزنید. |

| 🗑️ **من نمی توانم فایل را حذف کنم، حتی به عنوان مدیر!** | این اسکریپت به درستی کار می کند! برای مسدود کردن همه، از جمله شما، طراحی شده است. برای حذف آن، مراحل بخش **[نحوه لغو](#️-هشدارهای-مهم-و-نحوه-لغو)** را دنبال کنید. |
| 🤔 **چرا اجرای به عنوان `SYSTEM` اینقدر مهم است؟** | حساب `SYSTEM` بالاترین اختیار در ویندوز است. با قرار دادن `SYSTEM` به عنوان مالک طعمه، از تغییر آسان آن توسط حتی یک مدیر بدون گرفتن صریح مالکیت ابتدا جلوگیری می کند. بدافزاری که با حقوق مدیر اجرا می شود مسدود خواهد شد، که یک پیروزی بزرگ امنیتی است. |
